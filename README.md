# Dr. Franke Datenwissenschaften

Multi-page consultancy website built with Vue 3, TypeScript, Vue Router and Vite.

## Development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

The production output is written to `dist/`. The `public/404.html` fallback keeps
Vue Router routes working when deployed to GitHub Pages.
